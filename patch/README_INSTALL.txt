E.Y.E: Divine Cybermancy 한글 패치 (비공식 팬 번역) v0.2

[v0.2 변경 사항]
- 한글 폰트를 본고딕(Noto Sans KR)으로 교체해 작은 글씨의 깨짐을 줄임
- QHD·4K 등 고해상도에서 메뉴 글씨 크기가 해상도에 맞게 조정됨
- 모든 한글 글꼴에 안티앨리어싱 적용

[설치]
1. Steam 라이브러리에서 E.Y.E 우클릭 > 관리 > 로컬 파일 보기
   (보통 C:\Program Files (x86)\Steam\steamapps\common\EYE)
2. 이 압축 파일 안의 EYE 폴더를 위 폴더에 그대로 덮어쓰세요.
   (EYE\EYE\resource 안의 파일들이 교체·추가됩니다)
3. 게임 언어는 영어(English)로 두세요.

[되돌리기]
Steam에서 E.Y.E 우클릭 > 속성 > 설치된 파일 > 게임 파일 무결성 확인
(추가된 폰트 파일 NotoSansKR-*-EYE2.otf는 남아도 게임에 영향이 없습니다)

[주의]
- Steam이 게임을 업데이트하거나 무결성 확인을 하면 영어로 돌아갑니다. 다시 덮어쓰면 됩니다.
